# 动作/割草类分析模板 — Module A: 实体扫描

> 适用于：Vampire Survivors 类、Musou 类、横向/纵向割草、任何"大量敌人涌来、玩家以攻击/闪避应对"的动作游戏

## 使用说明

本模板是动作/割草类分析的第 1 个模块（共 4 个）。执行顺序：A → B → C → D。

**认知任务类型**：广度优先搜索。遍历代码找所有实体类型，不做属性分析。

**产出**：扫描清单文档——只记录"什么东西存在、在哪里"，不做属性分析。后续模块通过本清单分配的实体 ID 引用。

**评估重点**：完整性——是否遗漏了代码中的任何实体类型？

---

## Module A: 实体扫描

扫描方式：遍历代码中所有与实体类型相关的类、枚举、配置表、Prefab，提取每种实体的基本信息。

### 敌人清单

扫描代码中所有 Enemy/Monster/EnemyType 相关的类、枚举、配置表、Prefab：

| 字段 | 说明 |
|------|------|
| ID | 唯一标识，格式 `enemy_NNN`（如 enemy_001、enemy_002） |
| 名称 | 敌人类型名（类名/Prefab名/配置表ID） |
| 分类 | 小怪 / 精英 / Boss |
| 代码位置 | 定义该敌人的主要类名和文件路径 |
| 一句话描述 | 这个敌人做什么（如"直冲近战小怪"、"释放弹幕的精英"、"第一关Boss"） |

### 弹幕/投射物清单

扫描代码中所有 Projectile/Bullet/ProjectileType 相关的类、枚举、配置表、Prefab：

| 字段 | 说明 |
|------|------|
| ID | 唯一标识，格式 `projectile_NNN`（如 projectile_001） |
| 名称 | 弹幕/投射物类型名 |
| 来源敌人 | 该弹幕由哪个敌人发射（用 enemy ID 引用） |
| 代码位置 | 定义该弹幕的主要类名和文件路径 |
| 一句话描述 | 这种弹幕做什么（如"直线飞行子弹"、"追踪弹"、"定时爆炸弹"） |

### 评估重点

本模块的评估重点：**完整性**。

- 敌人清单是否覆盖了代码中所有 Enemy/Monster 相关的类和配置？
- 弹幕清单是否覆盖了代码中所有 Projectile/Bullet 相关的类和配置？
- 地形清单是否覆盖了代码中所有 Terrain/Obstacle 相关的类和配置？
- 玩家攻击清单是否覆盖了代码中所有 Attack/Weapon/Skill 相关的类和配置？
- 拾取物清单是否覆盖了代码中所有 Pickup/Item/Drop 相关的类和配置？
- 升级清单是否覆盖了代码中所有 Upgrade/SkillTree 相关的类和配置？
- 是否有遗漏的实体类型（如触发区域、特效区域、环境障碍等）？
