# 动作/割草类分析模板 — Module B: 实体深挖

> 适用于：Vampire Survivors 类、Musou 类、横向/纵向割草、任何"大量敌人涌来、玩家以攻击/闪避应对"的动作游戏

## 使用说明

本模板是动作/割草类分析的第 2 个模块（共 4 个）。执行顺序：A → B → C → D。

**前置依赖**：Module A 的扫描清单（实体 ID）。

**认知任务类型**：深度阅读。对 Module A 清单中的每个实体，精读其核心类和配置，提取详细属性。

**产出**：实体属性文档，按实体类别组织，用 Module A 分配的 ID 索引。

**评估重点**：准确性——每个实体的数值是否与代码/配置一致？行为描述是否与实现逻辑匹配？

## Module B: 实体深挖

基于 Module A 的扫描清单，逐个实体精读核心类和配置，提取详细属性。

### 敌人属性

对 Module A 清单中每个敌人类型（用 ID 索引），填写以下属性：

| 字段 | 说明 | 分析要点 |
|------|------|---------|
| ID + 名称 | 来自 Module A 清单 | 用清单 ID 索引 |
| 出现阶段 | 何时开始出现（第几波/第几分钟） | 决定 bot 是否需要在后期调整策略 |
| 数量密度 | 同时出现的典型数量 | 高密度 = 需要 AoE 优先处理 |
| 移动方式 | 直冲/环绕/定点/巡逻 | 直冲类需要闪避优先 |
| 攻击方式 | 近战碰撞/远程弹幕/范围 AoE/不攻击 | 弹幕类需要走位躲避 |
| 攻击频率 | 每次攻击间隔（秒） | 高频攻击即使伤害低也会累积威胁 |
| 单次伤害 | 每次攻击造成的伤害值 | 用于计算"能扛几下" |
| 特殊机制 | 爆炸/自爆/分裂/召唤/治疗/护盾 | 自爆和分裂类会连锁威胁 |
| 击杀收益 | 经验/金币/道具掉落概率 | 高收益敌人应被优先击杀 |
| 威胁等级 | 综合评估：致命/高/中/低 | 致命 = 必须优先躲避 |

### Boss 深挖

对 Module A 清单中每个 Boss（用 ID 索引），单独分析：

| 字段 | 说明 |
|------|------|
| ID + Boss 名称 | 来自 Module A 清单 |
| 出现条件 | 第几波出现 / 时间触发 / 特定事件触发 |
| 阶段转换 | 是否有多个阶段，转换条件是什么 |
| 每阶段攻击模式 | 阶段 1/2/3 各自的主要攻击方式列表 |
| 每阶段技能循环 | 技能释放顺序、冷却时间、预警信号 |
| 安全窗口 | Boss 攻击后有哪些可输出时间窗口，窗口持续多久 |
| 必躲技能 | 哪些技能必须闪避/走位躲开，命中后果 |
| 推荐应对策略 | 对该 Boss 的 bot 推荐行为 |

### 弹幕属性

对 Module A 清单中每种弹幕类型（用 ID 索引），填写以下属性：

| 字段 | 说明 | 为什么 bot 需要知道 |
|------|------|---------|
| ID + 名称 | 来自 Module A 清单 | 用清单 ID 索引 |
| 弹速 | 每种弹幕的飞行速度 | 弹速快的不等走位只能闪避 |
| 弹道模式 | 直线弹/追踪弹/扇形散射/环形弹幕/定时爆炸弹/穿透弹 | 直线弹侧步躲，追踪弹必须闪避打断锁定 |
| 弹幕存活规则 | 碰墙消失/碰地形消失/穿透地形继续飞行/时间到期消失 | 决定能否利用墙壁挡弹幕 |
| 弹幕碰撞体积 | 实际碰撞判定的大小（视觉大小 ≠ 碰撞大小） | 决定安全缝隙有多宽 |
| 预警信号 | 弹幕发射前是否有蓄力动画/地面标记，持续多久 | bot 最大的提前反应窗口 |

### 地形属性

对 Module A 清单中每种地形类型（用 ID 索引），填写以下属性：

| 字段 | 说明 | 为什么 bot 需要知道 |
|------|------|---------|
| ID + 名称 | 来自 Module A 清单 | 用清单 ID 索引 |
| 对玩家移动影响 | 无影响/减速/滑行(冰面)/阻挡/持续伤害 | 在水池中闪避距离打折，冰面闪避后额外滑行 |
| 对敌人移动影响 | 阻挡(绕路)/阻挡(原地)/穿透/减速 | 阻挡后绕路的敌人路径可预测 |
| 对子弹穿透性 | 阻挡(子弹碰此地形消失)/穿透(子弹穿过不受影响)/减速(子弹穿过但减速) | 墙壁挡子弹 → 可以躲在墙后；水池不挡子弹 → 不能靠水池挡弹幕 |
| 战术利用方式 | 挡弹幕/漏斗聚怪/分割战场/卡住敌人/减速敌人 | 地形不只是障碍，是战术资源 |

### 玩家攻击属性

对 Module A 清单中每种玩家攻击（用 ID 索引），填写以下属性：

| 字段 | 说明 |
|------|------|
| ID + 名称 | 来自 Module A 清单 |
| 伤害范围 | 命中区域形状和大小（圆形/扇形/矩形/全屏） |
| 攻击频率 | 释放间隔或触发条件 |
| 攻击伤害 | 基础伤害值 |
| 联动效果 | 击退/减速/冻结/灼烧/眩晕 |
| 穿透敌人数 | 0 = 不穿透，1 = 穿一个，-1 = 穿无限 |
| 冷却时间 | 技能冷却秒数，0 = 无冷却/自动攻击 |
| 自动攻击 | 是否自动触发（光环、炮塔等） |

### 拾取物属性

对 Module A 清单中每种拾取物（用 ID 索引），填写以下属性：

| 字段 | 说明 |
|------|------|
| ID + 名称 | 来自 Module A 清单 |
| 效果数值 | 回血量/经验值/持续时间等 |
| 拾取方式 | 磁吸范围(多少距离自动飞向玩家)/手动拾取(需要走过去) |
| 触发条件 | 击杀掉落/固定间隔生成/受伤触发 |

### 升级选项属性

对 Module A 清单中每种升级类型（用 ID 索引），填写以下属性：

| 字段 | 说明 |
|------|------|
| ID + 名称 | 来自 Module A 清单 |
| 效果描述 | 该升级的具体效果 |
| 联动加成 | 与哪些已有升级有组合效果 |
| 适用阶段 | 前期优先/后期优先/全程适用 |

### 评估重点

本模块的评估重点：**准确性**。

- 每个实体的数值字段（伤害、频率、弹速等）是否与代码/配置表中的实际值一致？
- 行为描述（移动方式、攻击方式、弹道模式等）是否与实现逻辑匹配？
- Boss 阶段转换条件和技能循环是否与代码逻辑一致？
- 弹幕存活规则和碰撞体积是否与实际碰撞代码一致？
- 地形属性（穿透性、移动影响等）是否与实际物理代码一致？
